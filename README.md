這是一支 Claude 技能，把「AI 生設定圖 → Tripo 生 3D → Blender 手修」這條線整理成 8 關 SOP。
以前要做一隻吉祥物的 3D 版，得先找 3D 師開 Blender 從零捏起，光估工時就要開一次會；現在 AI 幾十秒給你一個六成像的粗胚，剩下四成才是人要花的時間。
看完這篇，你會知道哪幾段真的能交給 AI、哪幾段還是要人，而且可以直接叫 Claude 帶你走一遍。

> [!NOTE]
> 這份技能是從三支同一位講者的實作影片筆記整理出來的，講者走的全是「可愛／動畫風」角色。寫實或硬表面沒驗證過，先別套。

## ✨ 這個技能能做什麼

| | 能做 | 白話說 |
|---|---|---|
| 🗺️ | 先畫分工流程圖 | 10～11 格，每格標「AI 做／人做」，卡關時知道卡在哪一格 |
| 🖼️ | 帶你生出可用的設定圖 | Character Sheet、A-pose 站姿圖、三視圖，還提醒你翻轉檢查對稱 |
| 🧩 | 拆零件再生 3D | 身體、頭、耳朵、裝備分開丟 Tripo，壞一塊只重做一塊 |
| 🛠️ | 用 Tripo 內建功能先修一輪 | 框選重做、智慧 UV、去除光影，少進 Blender 一次 |
| 🔧 | 帶你在 Blender 修拓撲與雕刻 | 具體到快捷鍵（M→At Center、Ctrl+L、Shift+H）與 Mirror 做眼睛 |
| ⚖️ | 幫你判斷什麼該給 AI | 道具配角給 AI、主角眼睛留人工、全自動化先別碰 |

做不到的也先講：貼圖烘焙、Rigging、匯出到 UE5，三篇筆記都只在流程圖帶過，這支技能目前在「模型修好」就停。缺的都列在 [docs/GAPS.md](docs/GAPS.md)。

## 🚀 怎麼用

### 裝進 Claude Code

把整個資料夾放進專案的 `.claude/skills/` 底下就好：

```bash
# 在你的專案根目錄
mkdir -p .claude/skills
cp -r ai-3dcharacter .claude/skills/ai-3dcharacter
```

或者放到個人層級，所有專案都能用：

```bash
cp -r ai-3dcharacter ~/.claude/skills/ai-3dcharacter
```

### 怎麼觸發

直接跟 Claude 講這些話，它就會載入技能：

- 「幫我用 AI 做一隻 3D 角色」
- 「這張吉祥物設定圖怎麼轉 3D」
- 「用 Tripo 生模型要注意什麼」
- 「AI 生的模型進 Blender 怎麼修」
- 或直接打 `/ai-3dcharacter`

> [!IMPORTANT]
> 開工前 Claude 會先確認幾件事：角色風格、你用哪套生圖工具、要做到哪一步、會不會 Blender 基本操作。缺什麼它才問，一次問一個，不會一口氣丟十個問題。

### 跑起來長這樣

```
你：幫我把公司的南瓜吉祥物做成 3D
Claude：先確認一下，你手上有角色設定圖了嗎？（有／沒有）
你：有一張正面圖
Claude：好，從第 2 關開始。先檢查這張是不是站直、四肢張開……
```

## 📚 這些書在講什麼

三篇筆記的講者是同一位：素人がAIで作ってみた。他不是 3D 老手，走的是「AI 出草稿、人來收尾」的路線。下面每篇先寫他的主張，再寫我們讀完的判斷，兩者分開。

### 《用AI生圖＋3D生成，做出一隻動畫兔角色》

**講者在講什麼**：先畫一張 AI 建模工作流程圖再動手，這張圖是全片最值錢的東西。角色要先有「身分證」（Character Sheet）與對齊的三視圖，然後拆成裸模、五官、服裝分開生 3D，一次生整隻壞一塊就全部重來。AI 給的是八成像，剩下兩成進 Blender 對照設定圖一刀一刀雕，用對半鏡射省一半時間。

**我們的判斷**：這篇最適合當公司的入門教材，因為它把「AI 做哪段、人守哪段」講得最清楚。拆零件的做法我們認為可以直接用，而且不只 3D，簡報與影片素材的版本管理也適用。要調整的是它完全沒有數字，面數、解析度、要重生幾版都得自己補。「Blender 還是要會一點」這句我們信，美術組以外的人跟做前要先摸過移動旋轉縮放。

### 《花200小時用AI做3D角色，學到什麼》

**講者在講什麼**：他實際花了 200 小時用 Tripo 加 Blender 做一整組角色，畫面右上角的計時器一路跳到 131 小時。結論是 AI 只負責 11 格流程裡的 3 格，「從零到一」很快，「從六十分到可用」還是人，那 20 分常佔一半工時。量產的訣竅是多視角設定圖與零件庫。他最後想用 API 全自動化，自己把流程圖標成 NG 版：Smart Mesh 在 API 上用不到，而且自動生完後修正反而變多。

**我們的判斷**：這篇不是教學，是真實工時紀錄，所以我們把它放進判斷表而不是步驟。最有用的兩條：道具、配角、場景小物優先給 AI，主角與特寫留人工；規劃任何自動化前先列「只有 UI 有、API 沒有」的功能。這兩條我們覺得可以直接寫進專案估算的 SOP。要存疑的是 200 小時這個數字，那是他邊學邊做的時間，不能拿來估我們的工時，要自己計時一次。

### 《用AI做3D角色，從一張圖到完整模型》

**講者在講什麼**：先跟 Claude 聊角色設定，生一張正面、站直、四肢張開的站姿圖，丟 Tripo 時選分件、四角面、面數 2,000～6,000。Tripo 自己就能框選重做壞掉的區域、智慧 UV 自動展開、貼圖開去除光影。進 Blender 後可以接 Blender MCP 讓 Claude 用講的排場景，但要先備份。真正的工時在修拓撲：M→At Center 收破洞、Ctrl+L 選連通、Shift+H 只留要修的那塊，最後用 Mirror 做眼睛。

**我們的判斷**：三篇裡最能照著做的一篇，SOP 第 4 到 8 關大半來自這裡。參數與快捷鍵我們直接採用。要調整的是面數範圍，他做的是可愛小鹿，我們的案子如果要進 UE5 跑即時，面數與拓撲標準要另外訂。Blender MCP 我們認為值得技術組試，它是「AI 直接操作桌面軟體」的實例，但筆記沒講怎麼裝，而且它改真檔的風險講者自己也提醒了。

## 🧭 怎麼應用

這三個情境是夥伴真的會碰到的，不是泛泛的「很多地方都能用」。

### 情境一：行銷要公司吉祥物的 3D 版，先給內部看

**誰、遇到什麼**：行銷夥伴有一張南瓜吉祥物的平面設定圖，想要一個 3D 版放在簡報與官網示意，不需要動。
**照哪幾關走**：從第 2 關開始檢查設定圖是不是 A-pose，第 3 關補三視圖、拆成身體與配件，第 4 關 Tripo 分件生成，第 5 關用內建功能修一輪就停。
**預期得到什麼**：半天內有一版可以轉圈看的粗胚，拿去內部討論夠用；確定方向後再排美術進第 6～8 關。

### 情境二：PM 要估一個「做 10 隻角色」的案子

**誰、遇到什麼**：客戶要一組 10 隻同風格的可愛角色，PM 要在報價前知道 AI 能省多少。
**照哪幾關走**：先用第 1 關畫流程圖，每格標 AI／人；用判斷表決定哪幾隻是主角（留人工）、哪幾隻是配角（AI 為主）；第一隻完整走 8 關並計時，之後用零件庫（眼睛、耳朵、衣服）量產。
**預期得到什麼**：一張標好分工的流程圖，加上第一隻的實測工時，報價有依據；而且知道後段手修才是大頭，不會被「AI 30 秒生成」騙到。

### 情境三：訓練場景要一批道具與配角

**誰、遇到什麼**：UE5 專案（例如訓練場）需要滅火器、工具箱、路人 NPC 這類不會被特寫的東西。
**照哪幾關走**：道具類照判斷表直接給 AI，第 4 關 Tripo 生完、第 5 關展 UV 就交付；配角 NPC 走到第 7 關修拓撲，確保動作不皺。
**預期得到什麼**：道具一天可以出一批；但匯進 UE5 的格式、尺度、軸向筆記沒講，要技術組先訂一次匯出規格（見還缺什麼）。

## 📖 名詞對照

| 名詞 | 白話 | 在這篇的角色 |
|---|---|---|
| Tripo | 丟一張圖，幾分鐘生出 3D 模型的線上服務 | 第 4、5 關主工具 |
| Blender | 免費的 3D 軟體，雕模型、上色、綁骨架都行 | 第 6～8 關主工具 |
| Character Sheet | 角色的「身分證」：正面、配件、配色一張定案 | 第 2 關產出 |
| 三視圖 | 正面、側面、背面三張對齊的圖 | 餵 Tripo 才不歪 |
| A-pose | 站直、四肢張開的站姿 | AI 最好轉 3D 的姿勢 |
| Mesh／Topology | 網格，以及網格的線怎麼排 | 第 7 關修的東西 |
| Quad | 四角面，變形才順 | Tripo 輸出選項、修拓撲目標 |
| UV 展開 | 把立體模型攤平成一張圖才能貼圖 | Tripo 智慧 UV 自動做 |
| Remove Lighting | 把原圖陰影洗掉再貼上去 | 第 5 關貼圖選項 |
| Smart Mesh | Tripo 自動整理網格的功能 | API 上用不到 |
| Mirror | 只做左半邊，右半邊自動複製 | 第 8 關做眼睛 |
| Rigging | 在模型裡裝骨頭讓它會動 | 流程圖有、步驟待補 |
| MCP | 讓 AI 直接操作某個軟體的橋 | Blender MCP，第 6 關可選 |

## ❓ 常見問題

<details>
<summary><b>AI 生完不就結束了嗎？為什麼還要 Blender？</b></summary>

三篇講者講法一致：AI 給的是六到八成，臉部網格會亂、耳朵連著頭、手指黏成一塊。要做動作、要被特寫，就得進 Blender 重拉線。一小時的影片裡超過 40 分鐘都在手修，這是真實比例。
</details>

<details>
<summary><b>可以一次生整隻角色嗎？</b></summary>

可以，但不建議。壞一塊就全部重來，細節解析度也不夠。至少拆成身體、頭、耳朵、裝備四組。
</details>

<details>
<summary><b>想用 API 把流程全自動化行不行？</b></summary>

講者試過，自己標成 NG 版。兩個原因：Smart Mesh 在 API 上用不到，以及自動生完後修正反而變多。先列出哪些功能只有 UI 有，再決定。
</details>

<details>
<summary><b>要先會 Blender 嗎？</b></summary>

至少要會移動、旋轉、縮放和基本雕刻。不想背快捷鍵可以裝 Gizmo 外掛用拖的。完全沒碰過的人，先把影片當流程觀摩。
</details>

<details>
<summary><b>Blender MCP 安全嗎？</b></summary>

方便，但它改的是你真的檔案。接上之前先存備份，這是講者自己踩過的提醒。
</details>

<details>
<summary><b>生出來的東西可以商用嗎？</b></summary>

筆記只提醒「先確認服務條款」，沒講內容。對外案子用之前，PM 要查一次生圖工具與 Tripo 的授權。
</details>

## 🧩 還缺什麼

這支技能是從筆記整理的，筆記沒講的我們不補。目前最需要人來補的：

1. **後半段流程**：貼圖烘焙、Rigging、匯出到 UE5，三篇都只在流程圖帶過。
2. **工具版本與方案**：Tripo 的 Quad、Smart Mesh 在哪個方案才有；Blender MCP 怎麼裝。
3. **驗收標準**：面數怎麼選、拓撲修到什麼程度算好、一隻角色平均幾小時。
4. **授權**：AI 生成素材商用的條款內容。

完整 14 條與「給南瓜的問題」見 [docs/GAPS.md](docs/GAPS.md)。審思過程在 [docs/AUDIT.md](docs/AUDIT.md)，萃取出的概念、步驟、參數、判斷、坑在 [docs/KNOWLEDGE.md](docs/KNOWLEDGE.md)。
