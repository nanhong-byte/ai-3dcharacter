# 萃取：用AI生圖＋3D角色

從三篇筆記撈出「真的能照著用」的東西。每一列都寫來自哪篇；筆記沒講的不補。
篇名縮寫：《兔》＝用AI生圖＋3D生成，做出一隻動畫兔角色；《200》＝花200小時用AI做3D角色，學到什麼；《鹿》＝用AI做3D角色，從一張圖到完整模型。

## 1. 概念

| 名詞 | 白話 | 為什麼重要 | 來自 |
|---|---|---|---|
| AI 出草稿、人來收尾 | AI 負責「從零到有」，把起手式壓到幾十秒；「從有到好」還是人手修 | 估工時的根本前提：AI 省的是前段，不是全部；後段手修常佔一半以上時間 | 《兔》《200》《鹿》 |
| 工作流程圖 | 動手前先畫一張 10～11 格的步驟圖，每格標「AI 做／人做」 | 卡關時知道卡在哪一格，不會整個重來；也立刻看出哪段其實沒省到時間 | 《兔》《200》 |
| Character Sheet（角色設定圖） | 一張把臉、衣服、配件、配色全部定下來的「身分證」 | 後面所有 3D 工作的唯一依據；雕刻時要一直拿回來比對 | 《兔》 |
| 三視圖／多視角設定圖 | 正面、側面、背面對齊的圖 | 只有正面會讓 3D 歪；多視角餵給 AI 生 3D 形狀準很多 | 《兔》《200》《鹿》 |
| A-pose／T-pose 站姿圖 | 正面、站直、四肢張開的角色圖 | AI 最容易轉成 3D，衣服跟手腳不會黏在一起 | 《鹿》 |
| 拆零件（身體＋零件） | 裸模、五官、耳朵、衣服、帽子分開管、分開生 | 壞一塊只重做那塊；細節解析度較夠；Blender 裡好調位置 | 《兔》《200》《鹿》 |
| 零件庫 | 眼睛、耳朵、衣服做成可重複用的素材 | 量產一整組角色時不用每隻從頭做 | 《200》 |
| Topology（拓撲）與 Quad | 網格線怎麼排；業界習慣全部四角面 | 線排不整齊，上色會歪、做動作會皺；這步省下來後面十倍麻煩 | 《鹿》《200》 |
| Mirror 鏡像 | 只做左半邊，右半邊自動複製 | 省一半工，而且保證對稱 | 《兔》《鹿》 |
| Blender MCP | 讓 Claude 直接操作 Blender 的橋 | 可以用講話的方式排物件、貼參考圖；但它改的是真檔 | 《兔》《鹿》 |

## 2. 步驟

| 順序 | 做什麼 | 用什麼工具 | 預期結果 | 來自 |
|---|---|---|---|---|
| 1 | 先畫工作流程圖，每格標 AI 做或人做 | 紙筆或任何畫圖工具 | 一張 10～11 格的流程圖，從設定到成品 | 《兔》《200》 |
| 2 | 跟 AI 聊角色設定：什麼生物、穿什麼、個性；請它一次生多張概念圖，挑一張當基準 | Claude（聊設定）＋生圖工具 | 一張選定的概念圖；配件（如帽子）另外設計幾版 | 《鹿》 |
| 3 | 做 Character Sheet：臉、衣服、包包、配色一次定下來 | 生圖工具 | 一張角色設定圖定稿 | 《兔》 |
| 4 | 生正面、站直、四肢張開的角色圖（A-pose） | 生圖工具 | 一張正面站姿圖，衣服與手腳不相黏 | 《鹿》 |
| 5 | 把角色轉成三視圖（正面、側面、背面），確認對齊；左右翻轉檢查對稱 | 生圖工具 | 三張對齊的視角圖；翻轉後不覺得怪 | 《兔》《200》《鹿》 |
| 6 | 先生裸模（沒穿衣服的本體），五官單獨拉出來，每個零件存獨立檔案 | 生圖工具＋檔案管理 | 裸模正面圖（確認比例與頭身比）、五官素材、服裝素材各一檔 | 《兔》 |
| 7 | 上傳圖到 Tripo，設定參數（面數上限、風格、分件、四角面），按生成，等進度條 | Tripo | 幾十秒到幾分鐘後出現一個有 Mesh 的 3D 粗胚；畫面會先跑點雲 | 《兔》《鹿》 |
| 8 | 身體、頭、耳朵、裝備分開生成；同一零件不滿意就重生幾版 | Tripo | 每個零件各一個 3D 檔 | 《兔》《鹿》 |
| 9 | 用 Tripo「編輯 Mesh」框出有問題的區域（褲子、凹陷），讓 AI 只重做那一塊 | Tripo | 框選區域被重生，其他部分不變 | 《鹿》 |
| 10 | 用 Tripo 智慧 UV 自動展開；貼圖生成時開「去除光影（Remove Lighting）」 | Tripo | 展開圖直接可用；貼到模型上沒有烙印的陰影 | 《鹿》 |
| 11 | 在繪圖軟體上補臉頰腮紅等臉部細節 | 繪圖軟體 | 貼圖上有補好的細節 | 《兔》 |
| 12 | 把所有零件匯進 Blender 組裝；要用 Blender MCP 之前先存一份備份 | Blender（可選 Blender MCP＋Claude） | 角色與配件都在場景裡排好位置；參考圖貼成背景板 | 《兔》《鹿》 |
| 13 | 修拓撲：M→At Center 合併頂點收破洞；Ctrl+L 選連通；Ctrl+L→Shift+H 只留要修的那塊；眼窩、耳朵、角、手臂接縫重拉線成 Quad | Blender | 面盡量都是四角面；沒有破洞；接縫處不黏 | 《鹿》 |
| 14 | 對照設定圖雕刻：頭的圓度、後腦杓弧線、眼睛位置大小、耳朵接頭、臉頰到下巴過渡；用對半鏡射只修一邊 | Blender Sculpt＋Mirror | 轉各視角都像設定圖；每修一陣子疊回參考圖比一次 | 《兔》 |
| 15 | 眼球用球體壓扁塞進眼窩；睫毛另拉片狀網格包眼睛上緣；用 Mirror 修改器以身體中線為軸鏡射 | Blender | 做完左眼右眼自動出現且對稱 | 《鹿》 |
| 16 | 修完回 Tripo 重新上色、重生貼圖（可能來回幾趟） | Tripo | 修過的模型有新貼圖 | 《200》 |

筆記只在流程圖提到、沒有步驟的：貼圖烘焙、Rigging、匯出成品、用 Higgsfield 做動畫。這些不寫成步驟，列進 GAPS。

## 3. 參數與數字

| 項目 | 值 | 前提 | 來自 |
|---|---|---|---|
| Tripo 面數設定 | 2,000～6,000 之間挑 | 面數越高越細，但越難編輯、檔案越大；影片是做可愛角色 | 《鹿》 |
| Tripo 輸出面型 | 選四角面（Quad） | 新版才支援；線會整齊很多 | 《鹿》 |
| Tripo 生成等待 | 幾十秒（《兔》）到幾分鐘（《鹿》） | 單一零件、單張圖 | 《兔》《鹿》 |
| 手修佔比 | 《鹿》一小時影片裡超過 40 分鐘在手修；《200》說後 20 分常佔一半工時 | 講者經驗，不是規則 | 《鹿》《200》 |
| 流程格數 | 10～11 格，AI 只負責其中 3 格（圖片生成、3D 生成、貼圖相關） | 講者自己的流程 | 《200》 |
| Blender 快捷鍵 | M→At Center（合併頂點）；Ctrl+L（選連通）；Shift+H（隱藏未選取） | Blender 編輯模式 | 《鹿》 |

## 4. 判斷規則

| 如果… | 就… | 為什麼 | 來自 |
|---|---|---|---|
| 要做的是道具、配角、場景小物 | 交給 AI 生，直接用 | 道具類生成品質相當夠用（南瓜頭、小丑、帽子、心臟都示範過） | 《200》 |
| 要做的是主角或會被特寫的部分（尤其眼睛） | 保留人工修 | AI 很難把「可愛的眼神」做對，眼睛幾乎全手工 | 《200》 |
| 想用 API 把整條流程自動化 | 先列出哪些功能只有 UI 有、API 沒有 | 講者的自動化流程圖被自己標成 NG 版：Smart Mesh 在 API 用不到，且自動生完後修正反而變多 | 《200》 |
| 要量產一整組角色 | 先建眼睛、耳朵、衣服的零件庫，再組 | 不用每隻從頭做 | 《200》 |
| 參考圖有陰影或姿勢不正 | 重生參考圖：用張開四肢的站姿；貼圖時開去除光影 | 不然生出來的模型一定歪，陰影會烙在身上 | 《鹿》 |
| 生出來的零件壞一塊 | 只重生那塊（Tripo 編輯 Mesh 或重上傳該零件） | 分零件生成才改得動 | 《兔》《鹿》 |
| 完全沒碰過 3D | 先把影片當流程觀摩，不急著跟做；至少要會移動、旋轉、縮放、基本雕刻 | AI 沒有取消「懂 3D」這件事；不懂 Retopology、UV、Rigging 就看不出 AI 給的哪裡壞 | 《兔》《200》 |
| 不想背 Blender 快捷鍵 | 裝 Gizmo 外掛用拖的 | 入門痛苦度降一半 | 《兔》 |
| 要接 Blender MCP 讓 AI 動場景 | 先存備份 | MCP 改的是真的檔案，一句話就可能刪光 | 《鹿》 |
| 想抄流程 | 看兔子篇前 20 分鐘就夠；想學修模技巧才看後段 | 影片八成是實際操作畫面 | 《兔》 |
| 要對外商用 AI 生成素材 | 先確認服務條款與授權 | 講者提醒，細節沒講 | 《鹿》 |

## 5. 坑

| 症狀 | 原因 | 解法 | 來自 |
|---|---|---|---|
| 生出來的設定圖左右不對稱 | 生圖工具常見問題 | 生完把圖左右翻轉看一次，不對勁就重生 | 《兔》 |
| 整隻角色生出來壞一塊，只能全部重來 | 一次生整隻 | 拆零件分開生 | 《兔》 |
| 3D 模型歪、只有正面好看 | 只用正面圖，或三視圖沒對齊 | 先做對齊的三視圖／多視角設定圖再生 3D | 《兔》《200》 |
| 衣服跟手腳黏在一起 | 參考圖姿勢不正 | 用正面、站直、四肢張開的站姿圖 | 《鹿》 |
| 陰影烙在模型上 | 原圖有光影 | 貼圖生成時開「去除光影」 | 《鹿》 |
| AI 生的臉部網格很亂；耳朵連著頭、手指黏成一塊 | AI 生成的拓撲一定有破綻 | 進 Blender 重拉線；用 Tripo 編輯 Mesh 先重做局部；選 Quad 輸出會整齊些 | 《200》《鹿》 |
| 越修越偏離原設定 | 雕刻時沒比對參考圖 | 每修一陣子把參考圖疊回來比一次 | 《兔》 |
| 鏡射後兩邊錯開 | Mirror 軸沒對準身體中線 | 以身體中線為軸再鏡射 | 《鹿》 |
| 用 MCP 後檔案被改壞救不回 | MCP 直接改真檔 | 接 MCP 前先備份 | 《鹿》 |
| 全自動化流程做完才發現斷鏈 | 關鍵功能（如 Smart Mesh）只在 UI 有，API 沒有 | 規劃前先列 UI 有／API 沒有的功能 | 《200》 |
| 自動生出一堆角色，後面修正時間反而暴增 | 生成快但品質不穩，修正是人工 | 不追求全自動；AI 只負責前 3 格 | 《200》 |
