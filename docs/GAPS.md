## 流程缺口（後半段完全沒有步驟）
1. **貼圖烘焙與最終貼圖**：筆記只在流程圖提到「貼圖」，沒有任何操作步驟（Tripo 生貼圖之後怎麼接 Blender、要不要烘焙）。需要它才能把模型用在引擎裡。可補：美術組有做過 Texture Bake 的人。
2. **Rigging（綁骨架）**：三篇都只在流程圖帶過。沒有它角色不能動。流程圖截圖（assets/shots/01-03.jpg）標的工具是 AccuRIG／AutoRigPro（自動配置＋權重修正），匯入引擎是 Unity；只有工具名，沒有步驟。可補：動畫組，或等講者後續影片。
3. **匯出成品與匯入引擎**：沒講匯出格式（FBX／glTF）、尺度、軸向。公司的案子（海軍訓場、允和）都進 UE5，這段最需要。可補：UE5 技術組。
4. **用 Higgsfield 做動畫短片**：小鹿篇只有開頭一句「丟進 Higgsfield 變成動畫」，沒步驟、沒參數。可補：看講者原片後段或試用一次。
